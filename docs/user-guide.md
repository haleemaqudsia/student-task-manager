# User Guide

From the project folder, run `python main.py`.

1. Choose `1` and enter a title such as `Study Python`.
2. Choose `2` to display your tasks and find the task ID.
3. Choose `3` and enter the ID to mark the task as completed.
4. Choose `4` and enter the ID to delete the task.
5. Choose `5` to exit.

Blank titles are rejected. Enter a numeric task ID when completing or deleting
a task. Tasks are stored in memory and reset when the app closes.
